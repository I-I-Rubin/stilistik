# stilistik
Lateinische Stilistik für Deutsche; by Nägelsbach, Karl Friedrich von, 1806-1859; Müller, Iwan von, 1830-1917

The script in the outer directory illustrates the use of the llamaparse https://www.llamaindex.ai/llamaparse 'API' to parse a chunk of complex Fraktur scholarship while retaining what is needed to get solid markdown for translation.  It is easy to get the api key for free and I think several hundred free pages a month.  Any advanced AI can explain this.

The inner directory einleitung shows the initial output of the parser then a couple german markdown files chatgpt produced on the way to einleitung_de.md then translation to einleitung_de.md.   Ideally there should be a glossary that is specific to this domain.  I include others I use for other purposes as illustration. The final bilingual html file should not properly appear here, but is produced by the script table.sh which uses python and the markdown library.  The subdirectory typst can produce a two column bilingual version if typst is installed; the other is just english produced by latex (in fact typst could do this more easily).  

Again, any advanced LLM can explain this if you download the zipped directory under <>Code above and let the ai inspect it.    Everything about it is extremely simple.  The difficult part I think is to inspect ye old chapter and discuss how to write the special instructions in 'agentic_options= ..." in a new version of parse_fraktur.py The pdf Urschrift will be the result of an eccentric scholar, a cheeseparing publisher and a surly 19th c German typesetter.  An LLM like Claude or Chatgpt can write the python and the crucial 'agentic options' part in discussion, after you think through the document.   I include discussion chatgpt.md of the fallible process that turns the hideous llamaparsed Fraktur output into the lovely lateinish type einleitung_de.md file. The latter has exactly the shape for proper scientific translation by contemporary LLMs (especially if one had a proper sytematic German-English glossary for leading terms of Latin studies.)  One ends up with two parallel markdown files one can inspect side by side in an editor - I was using sublime text here fwiw.
