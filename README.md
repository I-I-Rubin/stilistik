# stilistik
Lateinische Stilistik für Deutsche; by Nägelsbach, Karl Friedrich von, 1806-1859; Müller, Iwan von, 1830-1917

The script in the outer directory illustrates the use of the llamaparse https://www.llamaindex.ai/llamaparse 'API' to parse a chunk of complex Fraktur scholarship while retaining what is needed to get solid markdown for translation.  The inner directory einleitung shows the initial output of the parser then a couple german markdown files chatgpt produced on the way to einleitung_de.md then translation to einleitung_de.md.   Ideally there should be a glossary that is specific to this domain.  I include others I use for other purposes as illustration.
